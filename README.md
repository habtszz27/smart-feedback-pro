# Smart Feedback

An AI-powered feedback collection app that analyzes user sentiment using GPT and presents insights in a clean dashboard.

## Features

- Collects open-text feedback
- Analyzes sentiment using GPT
- Displays categorized insights on a dashboard
- Built with **React**, **Node.js**, **Express**, **MongoDB**, and **OpenAI**
- Deployed on **Render**

- Node.js + Express
- MongoDB with Mongoose
- OpenAI API for sentiment analysis
